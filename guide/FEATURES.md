# 마을에 무엇이 있나

[← 문서 색인](README.md)

핵심은 **"머무를 이유 · 만날 시간 · 자랑할 것 · 만들 거리 · 함께 싸울 상대"** 다섯 축이다.

## 🧺 장사와 거래 — 머무를 이유

아무 곳에나 노점을 편다(개설+가격이 `openStall` 단일 tx로 온체인). **접속을 끊어도
노점은 마을에 남는다.** 구매는 에스크로+ERC-1155 쿠폰이고, **흥정**(오퍼)으로 값을
부를 수 있다. 쿠폰은 **선물·사용(소각)** 까지 된다. 아바타를 클릭해 ETH를 보내는
선물도 마찬가지로 온체인이다.

- 대금은 에스크로에 보관 — 구매자가 확정하거나 24시간 뒤 자동 정산, 분쟁·환불 포함
- 값은 컨트랙트가 강제한다 — 리스팅 가격과 다르면 revert
- 흥정을 수락하면 **정산 + 쿠폰 전달이 한 트랜잭션**으로 끝난다

## 🏯 길드 + 백층 던전 — 비동기 코업

주차 시드는 **GIWA 블록 해시로 고정**되고, 문 결과는 시드+회차 해시로 결정된다.
함정을 밟으면 잃고, 귀환하면 길드 기록에 쌓인다 — 길드원들이 각자의 시간에 이어
등반하고, 상위 길드는 **광장에 깃발**이 게양된다.

결정론이라서 **누구나 남의 등반 기록을 재현해 대조할 수 있다** — 게임 서버도 지갑도
API 키도 필요 없다 ([TESTING.md](TESTING.md#검증-가능성-npm-run-verify)).
같은 결정론이 만드는 한계와 메인넷 대안은
[컨트랙트 문서](../contracts/README.md#메인넷-엔트로피--알려진-한계와-이관-계획)에 공개해 두었다.

## 🧿 도깨비 토벌 — 동시성 코업

광장의 주간 보스를 **함께** 때려잡는다(R 키, 쿨다운 30초). 데미지는 블록해시 롤 +
온기 보정이고, 개인·길드 기여가 온체인에 쌓인다. 토벌 기여자는 소울바운드 전리품을
받는다. 곁에 서면 배경음이 북이 붙은 토벌 트랙으로 갈아탄다.

## 🔥 모닥불 + 장날 — 만날 시간

광장 모닥불에 **함께** 앉으면(2명 이상) 온기가 쌓인다. 혼자서는 쌓이지 않는다.
매주 **토 21시(KST) 장날**엔 온기·도깨비 데미지가 2배 — 모두가 같은 시간에 모일 이유다.

## 🎨 꾸미기 + 창작 — 자랑할 것·만들 거리

- **칭호** — 온체인 기록으로 자격을 검증하는 소울바운드 업적. 이름표에 배지로 붙는다
- **랜덤박스 장신구** — 무료 뽑기(블록해시 open→reveal), 소울바운드 8종
- **문양 공방** — 8×8 픽셀을 직접 그려 온체인에 등록·판매·착용. **판매 대금은 창작자 직송**

## 🌗 주야 사이클 + 풍류

마을 시각은 **한국 시간(KST)을 그대로 따른다**. 해가 기울면 하늘빛이 변하고
저잣거리 등불에 불이 들어온다. 밤에도 주변광에 하한을 둬서 간판·이름표는 계속
읽힌다 — 여기서 밤은 난이도가 아니라 분위기다.

HUD의 **🎵 풍류**를 켜면 평조 5음계로 즉석 생성한 국악풍 배경음이 깔린다.
**배경음은 파일이 0바이트이고 같은 가락이 두 번 나오지 않는다** — 도깨비 곁에 서면
북이 붙은 토벌 트랙으로 갈아타고, 깎일수록 빨라진다. 효과음은 합성음과 반입한 CC0
조각을 섞어 쓰고, 모닥불처럼 자리가 있는 소리는 3D로 놓는다(귀는 카메라가 아니라
아바타에 달려 있다). 반입 조각의 출처·라이선스는 [ASSETS.md](../ASSETS.md) 참고.
기본은 꺼짐.

## 🪪 GIWA 네이티브 읽기 연동

- **Dojang Verified Address 실연동** — DojangScroll `isVerified(주소, 업비트 발행자 ID)`
  온체인 조회로 상인 인증을 표시한다: 🟡 *Dojang 인증 상인*(업비트 신원 인증) vs
  ✓ *지갑 상인*. "시각적으로 인증받고 거래"의 GIWA 네이티브 구현
  (버너 지갑은 미인증이 정상이다).
- **UP.ID(Upbit Web3 Names) 이름표** — UPNameRegistry에서 주소→이름 역방향 조회.
  이름이 있으면 아바타 이름표·HUD·노점 다이얼로그에 주소 대신 표시된다.
  (이름 등록에는 Dojang 인증이 필요 — 인증 상인 서사와 같은 축)

## 🧓 주민들

봇 주민들은 각자의 페르소나가 있어 가끔 자기다운 한마디를 흘린다. 명단·성격은
[data/npcs.json](../data/npcs.json) 하나가 단일 소스이고, LLM 상인 봇도 같은 파일을
읽는다 ([AGENTS.md](AGENTS.md)). 걸음 규칙은 순수 모듈(`client/src/demo/wander.ts`)
한 곳에 있어 `npm test`가 진짜 노점 배치 위에서 1분 산책을 그대로 돌려 본다.
