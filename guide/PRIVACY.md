# 개인정보 처리방침 (v0 초안)

> **초안이다. 법률 자문을 받아 쓴 글이 아니며, 법적 효력을 가진 최종본이 아니다.**
> 기와장터는 GIWA Sepolia **테스트넷** 위의 실험 프로젝트다. 이 글은 지금 코드가 실제로
> 무엇을 어디에 남기는지를 정직하게 적어 두려는 것이다. 정식 서비스 전에 전문가 검토를 받아 고친다.
> 시행일: (미정) · 판: v0 · 2026-09-26 작성

기와장터(이하 "마을")는 웹 브라우저 · Unity 앱 등 여러 클라이언트로 들어오는 3D 아바타 소셜 공간이다.
운영자는 **이름 · 전화번호 · 이메일 · 생년월일 같은 신원 정보를 받지 않는다.** 회원 가입이 없다.
대신 아래의 것들이 여러분의 기기, 공개 블록체인, 그리고 몇몇 제3자 서비스에 남는다.

---

## 1. 여러분의 기기에 남는 것

| 무엇 | 어디에 | 솔직한 설명 |
|---|---|---|
| **버너 지갑의 개인 키** | 웹: 브라우저 localStorage `giwa-demo-burner` | **암호화하지 않은 평문**으로 저장된다. 같은 브라우저 · 같은 사이트 주소(origin)에서 도는 다른 스크립트가 읽을 수 있고, 브라우저 데이터를 지우면 영영 사라진다(되살릴 방법이 없다). 테스트넷 전용 · 소액용이다. **진짜 자산이 든 지갑의 키를 이 자리에 넣지 말 것** |
| 버너 지갑의 개인 키 | Unity 앱: 기기 설정 저장소(PlayerPrefs) | Windows DPAPI · Android Keystore 로 감싸 둔다. iOS 판은 아직 없다 |
| 진행 기록 | localStorage `giwa-quest-*` · `giwa-welcome` · `giwa-daily*` · `giwa-ambience` 등 | 촌장의 부탁 단계 · 환영 카드 답 · 소리 설정. 기기 밖으로 나가지 않는다 |
| 쿠폰함 표시용 기록 | localStorage `giwa-coupons-<주소>` | 산 쿠폰의 표시용 사본. 정본은 체인에 있다 |
| 분석용 설치 ID · 초대 토큰 | localStorage `giwa-install-id` · `giwa-invite` | **분석이 켜진 빌드에서만** 만든다(§4). 무작위 값이며 지갑 주소와 무관하다 |

WalletConnect 로 **여러분의 진짜 지갑**을 이을 때(충전 한 번), 그 지갑의 개인 키 · 시드는 마을로 들어오지 않는다.
서명은 그 지갑 앱 안에서 이루어진다.

## 2. 공개 블록체인에 남는 것 — 지울 수 없다

마을의 거래 · 기록은 GIWA Sepolia(공개 테스트넷)의 스마트 계약에 쓰인다. **블록체인에 한 번 쓰인 것은
운영자도 지우거나 고칠 수 없고, 누구나 익스플로러로 읽을 수 있으며, 그 체인이 있는 한 남는다.**

| 무엇 | 언제 |
|---|---|
| 여러분의 **지갑 주소** | 모든 쓰기(구매 · 노점 · 흥정 · 도깨비 토벌 · 온기 · 칭호 · 복주머니 · 문양 공방)마다 |
| **위치 비컨** — 마을 안 좌표 · 이동 방향 · 이모트와 그 **시각** | 잔액이 조금이라도 있으면 약 2초마다 자동으로 쓰인다(프레즌스). 언제 어디에 서 있었는지가 공개 기록이 된다 |
| **노점 이름 · 품목 이름 · 가격** | 노점을 펼 때 |
| 구매 · 흥정 · 정산 · 환불 · 분쟁 신고 · 쿠폰 사용 · 선물 | 할 때마다(금액 · 상대 주소 포함) |
| 칭호 · 장신구 · 길드 · 던전 기록 · 문양(8×8 그림) | 얻거나 만들 때 |

지갑 주소 자체는 이름이 아니지만, 다른 정보(거래소 기록 · SNS 에 올린 주소 등)와 합치면 사람을 알아볼 수 있다.
**노점 이름 · 문양에 실명 · 연락처 같은 개인정보를 쓰지 말 것** — 지울 수 없다.

## 3. 실시간 서버(선택)

초대 테스트 창처럼 실시간 서버를 켤 때만, 접속한 동안 서버가 다음을 **메모리에** 든다:
표시 이름 · 아바타 색 · (서명해 알린 경우) 지갑 주소 · 마을 안 좌표 · 이모트. 영구 저장하지 않고,
나가면 지운다. 접속 기록(IP 등)은 호스팅 업체의 일반 로그에 남을 수 있다.

## 4. 분석(선택 · 기본 꺼짐)

분석 키를 넣고 만든 빌드에서만, 어떤 화면을 거쳤는지 · 첫 입력까지 몇 초였는지 같은 **사용 이벤트**를
보낸다. 항목은 [ANALYTICS.md](ANALYTICS.md) 에 다 적혀 있다.
**지갑 주소 · 주소 해시 · 거래 해시 · 키 · 여러분이 쓴 글은 보내지 않는다.** 식별자는 설치마다 만든 무작위 값이다.
목적은 첫 1분 · 5분이 어디서 막히는지 고치는 것뿐이고, 광고에 쓰지 않는다. 보관 기간은 (미정 — 정식판 전에 정한다).

## 5. 제3자 · 국외 이전

마을을 쓰는 동안 여러분의 기기가 아래 서비스와 직접 통신한다. 대부분 국외에 있다.

| 누구 | 무엇을 | 왜 |
|---|---|---|
| GIWA Sepolia 공개 RPC · 익스플로러(Blockscout) | IP · 조회하는 주소 · 보내는 거래 | 체인 읽기 · 쓰기 · 기록 조회 |
| WalletConnect(Reown) 릴레이 | IP · 암호화된 지갑 메시지 | 진짜 지갑으로 충전할 때(Unity) |
| GIWA 포셋 · 여러분이 고른 지갑 앱 | 그 서비스의 방침을 따른다 | 테스트 ETH 받기 · 서명 |
| 분석 수집처(예: PostHog) | §4 의 이벤트 · IP | **분석이 켜진 빌드에서만** |
| 실시간 서버 호스팅(예: Fly.io, 도쿄) | IP · §3 의 세션 정보 | **서버를 켠 때만** |
| 정적 호스팅(GitHub Pages) | IP · 요청 정보 | 페이지를 내려받을 때 |

## 6. 여러분이 할 수 있는 것

- 기기에 남은 것은 브라우저 데이터 삭제 · 앱 삭제로 지운다(버너 지갑도 함께 사라진다).
- 분석은 `?noanalytics` 를 붙여 열면 그 세션에서 꺼진다.
- **체인에 쓰인 것은 지울 수 없다** — 쓰기 전에 생각할 것.
- 문의 · 열람 · 정정 요청: 아래 연락처.
